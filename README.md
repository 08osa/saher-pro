# Saher Pro - Average-Speed Enforcement Prototype

Innovation-course team project. Existing speed cameras ("Saher") can be located by drivers, who then only slow down near the camera; **Saher Pro** measures a vehicle's **average speed between two checkpoints** instead.

## Prototype
- Two colour sensors at two checkpoints on a CNC-cut model road
- Arduino Uno measures the time between checkpoints and computes speed
- 16x2 LCD shows the result
- Future work: license-plate cameras, and combining instantaneous (Saher) and average (Saher Pro) speed
